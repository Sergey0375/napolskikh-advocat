# Premium-upgrade текущего сайта

Точечное визуальное обновление поверх существующего проекта: тёмная графитовая база и золотой акцент сохраняются, тексты, страницы, URL, контакты и данные кейсов не меняются. Премиальность достигается пространством, типографикой, единой сеткой и деликатными деталями.

## 1. Design tokens и базовые стили (`src/styles.css`)

- Добавить токены: ширина контейнера (1200px), паддинги контейнера по брейкпоинтам, вертикальные ритмы секций (120 / 96 / 72px), радиусы (8 / 12 / 18px), тонкая граница, мягкая тень, длительности переходов (180ms / 260ms).
- Типографическая шкала на `clamp()`: H1 ~52–64px, H2 ~38–46px, H3 ~22–28px, body 17–19px, caption 14–16px; line-height 1.05–1.2 для заголовков, 1.6 для текста.
- Убрать «неоновую» логику: приглушить свечения, снизить количество золотых элементов, повысить контраст `muted-foreground` до WCAG AA.
- Смягчить `panel`: тонкая граница, минимальная тень, единый радиус.
- Блок `@media (prefers-reduced-motion: reduce)` — отключение переходов и появлений.

## 2. Компонентная система (`src/components/site/`)

- `Container` — единая ширина и паддинги для всех страниц.
- `Section` — переиспользует Container, задаёт вертикальные отступы, варианты фона (base / subtle).
- `SectionHeader` — eyebrow / заголовок / лид с фиксированным ритмом и `max-width: 680–720px`.
- `Button` — три варианта: primary, secondary (outline), text link; высота 50px, единая анимация, видимый `:focus-visible`.
- `TrustStat`, `PracticeCard`, `CaseCard`, `MediaMention`, `ContactItem` — вынести повторяющуюся вёрстку из страниц.
- `CTASection` — спокойный контрастный блок вместо текущего `CtaBand`, тот же текст.

## 3. Header

- Больше воздуха, высота ~76px, тонкая нижняя граница, `backdrop-blur` и почти непрозрачный фон в sticky-состоянии, без тени.
- Активный пункт — деликатный, без рамок.
- Мобильное меню — аккуратный drawer, зоны нажатия ≥44px.

## 4. Главная страница

Последовательность из ТЗ: Hero → Trust bar → Практики → Подход → Кейсы → Об адвокате (кратко, ссылка) → СМИ/квалификация → FAQ → Final CTA. Новые смысловые блоки собираются из уже существующего контента, ничего не выдумывается.

- **Hero**: сетка 58/42, слева eyebrow + H1 + короткое позиционирование + CTA, справа портрет (радиус 16px, тонкая граница, без тяжёлой тени, priority-загрузка). Убрать перегрузку бейджами.
- **Trust bar**: 4 показателя — статус/реестр, практика с 2019, география, формат. Спокойная типографика, без крупных счётчиков.
- **Практики**: карточки крупнее и тише, номер направления вместо крупной иконки, заголовок крупнее, 2–3 строки описания, hover — `translateY(-2px)` + смена границы.
- **Кейсы на главной**: 3 сильных кейса в две колонки, результат и срок как отдельная строка (цифры и тексты без изменений).
- **FAQ**: 5–7 вопросов лёгким accordion'ом (тонкие разделители, +/–), без «панели».
- **Final CTA**: спокойный блок, одна основная кнопка + вторичная контактная ссылка.

## 5. Остальные страницы

- **Услуги**: тот же контент, новая карточная система, «Состав работ» визуально вторичен.
- **Кейсы**: две колонки, чёткое разделение категория → описание → результат/срок; цифры остаются как есть.
- **Об адвокате**: editorial-подача — фото + короткий профиль + 3–4 факта; опыт как аккуратная вертикальная timeline; дипломы: главные квалификации заметнее, дополнительные компактнее (карусель сохраняется, оформление облегчается); публикации — значимый trust-блок типографическим списком.
- **Вопросы**: accordion без boxed-карточек, тонкие разделители, padding 24px.
- **Контакты**: две колонки — слева заголовок, пояснение и контакты, справа форма; поля 52px, минимум рамок, ясный focus-state.
- **Footer**: лаконичный, имя/статус/реестр/контакты/навигация, без продающего блока.

## 6. Доступность и производительность

- Корректная структура H1–H6, `aria-label` для icon-кнопок, видимый focus, контраст AA.
- Hero-изображение с приоритетом, остальные — lazy; лишние начертания шрифтов не подключаются; тяжёлые анимации не добавляются.

## 7. Проверка

Визуальная проверка ключевых страниц на 1440 / 1280 / 1024 / 768 / 430 / 360 px, отсутствие горизонтальной прокрутки, сборка без ошибок.

## Что не меняется

Тексты услуг, кейсы и цифры, контакты, реестровый номер, факты об адвокате, URL, маршрутизация, смысл CTA, фото (используется существующий портрет), тёмная графитовая палитра.
